Body is the default reading size, and it is set large on purpose: a 17px measure with settled leading holds a paragraph of real explanation without the reader leaning in. Everything that is prose takes this role — card bodies, banner messages, modal copy — so a page has one reading size rather than four near-misses.

--text-caption15px · --leading-normal

Caption is small prose, not metadata. A sentence explaining a field or a footnote under a figure belongs here; a counter or a date does not, because 15px is generous for a number and 12px is too small for a sentence.

How this sets the density

Three families do three jobs. Prose is the larger of the two reading families and settled rather than airy — 17px on 1.35, which holds a paragraph together in the narrow column a card or a modal actually gives it. Chrome sits below it on the same scale — a 14px button beside 17px body is what makes an interface feel like an interface rather than a document. Meta is mono and fixed at 12px, for output a machine produced — the one place that step still belongs.

The gap between the prose and chrome families is the density dial for the whole system: widen it and the page reads editorial, close it and it reads like a dashboard. Individual components never pick a pixel — they pick a step — so this is one edit, not fifty.

--density scales control text and padding together, per theme. Core ships 1; Product and Roadtrip ship 0.92, which is the same components at dashboard density.

--density: 1 — core

--density: 0.92 — product, roadtrip

Prose does not scale with density. A dense dashboard still has to be readable, and shrinking body text is how a compact UI becomes an unusable one.
