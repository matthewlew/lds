A thumbnail is sized by RATIO, never by a width and a height. The height comes from the row — 30px compact, 38px default, 48px roomy — so a thumbnail can never set the row's height, and the width follows from the ratio. Three ratios exist and no more; a fourth is a new decision to make on purpose, not a one-off.

object-fit: cover on every one, with --surface-sunken behind it so a slow or missing image leaves a considered box rather than a hole.

Ratios

16:9 is the only ratio used full-bleed: it is the one that survives being cropped to a panel width. Do not put a 1:1 asset full-bleed — at 320px wide it eats the whole panel before a word of copy.

Overlay — full-bleed: the image IS the subject

Half Dome

Full-bleed escapes the body's padding, so it must be a direct child of the body. As the first child it inherits the panel's top corners; under a header bar it squares off, because the bar already owns that edge.

Use when the picture is what the overlay is about — a photo, a map, a preview.

Overlay — inset: the image SUPPORTS the text
Set a reminder

Inset keeps the body's padding and takes the base radius, so it reads as an illustration inside the copy rather than as the subject of the panel.

Both take aspect-ratio from --media-ratio (16:9 default) — never a fixed height, which crops differently at every panel width, and a side sheet's width changes with the viewport.
